# Программная реализация алгоритма фрактального сжатия изображений

Программная реализация алгоритма фрактального сжатия изображений,
разработанная в рамках научно-исследовательской работы.

# Возможности

Программа реализует:

- фрактальное кодирование изображений;
- адаптивное разбиение на блоки диапазона;
- поиск соответствующих доменных блоков;
- использование геометрических преобразований;
- подбор параметров контраста и яркости;
- сохранение фрактального представления;
- итерационное декодирование;
- расчет показателей MSE и PSNR;
- расчет коэффициента сжатия.

# Используемые технологии

- Python 3
- NumPy
- Pillow

# Конфигурация по умолчанию

- максимальный размер блока: 32×32 пикселя;
- минимальный размер блока: 4×4 пикселя;
- порог ошибки: 100;
- ограничение коэффициента контраста: 0,99;
- количество итераций декодирования: 8.


## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt

Поместить исходное изображение в каталог с программой и указать его
имя в конфигурации программы.

Запуск:

python main.py
